# P5 Web App Implementation Plan

> **For agentic workers:** Use anthropic-skills:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The Chinese web interface for the Phase B journey: upload, task progress, evidence review, commit, search, record detail and FASTA export.

**Architecture:** React with Vite, Ant Design (`zh_CN`), TanStack Query and React Router. API types are generated from `packages/contracts/api/openapi.json`, which the backend now describes precisely through response models (`api/schemas.py`). Offsets from the API are code points and are converted in `src/lib/codepoints.ts`.

## Tasks

- [x] **Task 1:** Package, TypeScript, ESLint, Prettier, Vitest; generated API types; API client with the CSRF header, development identity and error envelope.
- [x] **Task 2:** Code-point conversion and segmentation with tests (astral characters, CJK).
- [x] **Task 3:** Upload panel (formats and limits shown first, SHA-256 in the browser, per-file results) and task list (polling, committed and unresolved counts, cancel, reprocess).
- [x] **Task 4:** Review workspace: evidence viewer with name, sequence and issue highlights; candidate cards; resolutions from each rule's allowlist; no override for BLOCK; sequence edits with reason, fragment flag and character diff; approve, reject, archive; bulk approve; commit dialog with preview counts, one idempotency key and per-item results; 409 conflict prompt.
- [x] **Task 5:** Records search (name, project, length, exact sequence) and record detail with versions, provenance and FASTA export.
- [x] **Task 6:** Development stack (`scripts/dev_stack.py`, `entrypoints/dev_server.py`) and Playwright journeys: T02, T09, T12 and viewer permissions. CI jobs for the web app and E2E.
